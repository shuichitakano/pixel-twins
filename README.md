# Pixel Twins

**RP2350の力を使い切り、ローレベルI/OからゲームランタイムまでをAIで作る、
2人用ゲームコンソールです。**

Pixel Twinsは、横に並べた2枚の160×120ピクセルLEDパネル、2台のUSBゲームコントローラー、
ステレオ音声を1台のRP2350で動かすためのハードウェアとC++ランタイムです。
左右それぞれをプレイヤーの画面として使うことも、320×120ピクセルの横長なひとつの画面として
使うこともできます。

狙っているのは、市販のディスプレイとPCを組み合わせたゲームではなく、表示装置、基板、音源、
ゲームコードまでをひとつの作品として作れる、小さな自作ゲームプラットフォームです。

> 現在は開発中です。RP2350でのLED表示、2系統のUSB入力、音声出力まで実装し、
> 回路図と製造データを公開していますが、APIとハードウェアは今後も変更される可能性があります。

## このプロジェクトのコンセプト

Pixel Twinsは、RP2350の強力なCPU、PIO、DMA、SRAMを活かし、ビデオゲームに必要な一通りの
仕組みをAIでどこまで作れるか試すプロジェクトの一部です。

AIを既存エンジン上のゲームコード生成だけに使うのではなく、bit bangingを含むGPIO制御、
LEDパネル転送、USBホスト、音声出力といったローレベル層から、フレームバッファ、描画、音源、
シーケンサ、アセット変換までをひと続きのシステムとして開発します。その上で、同じ仕組みを使う
ゲームアプリケーションまで作ることを目標にしています。

このリポジトリが担当するのは、そのうちの**ゲームコンソール部分**です。
ハードウェア制御と、ゲームから利用する共通C++ランタイムを収録します。最初のゲームとして、
別プロジェクトで2人協力型アクションゲーム「Wizward」を開発しています。

```text
ゲームアプリケーション             Wizwardなど
────────────────────────────────────────
ゲーム向けランタイム               BG / sprite / font / input / sound
────────────────────────────────────────
ハードウェアランタイム             framebuffer / USB host / PCM / timing
────────────────────────────────────────
ローレベルI/O                     GPIO / bit banging / PIO / DMA / PWM
────────────────────────────────────────
ハードウェア                       RP2350 / LED panels / controllers / audio
```

## Pixel Twinsでできること

- 160×120ピクセルのLEDパネル2枚を、ひと続きの320×120ピクセル画面として描画
- 左右を独立した画面として扱う、または画面境界をまたぐスプライトを表示
- USBゲームコントローラー2台による2人同時プレイ
- 波形メモリ音源、BGM・効果音シーケンサ、PCMミキサーによるステレオ音声
- BG、スプライト、拡大縮小、プリミティブ、8×9フォントを動的メモリ確保なしで描画
- 同じゲームコードをmacOS上のSDL版とRP2350実機版で実行

## システム構成

```text
 USBゲームパッド × 2
          │
          ▼
┌──────────────────────────────┐
│ RP2350                       │
│                              │
│ ゲーム ─ 描画 ─ 音源         │
│            │       │         │
└────────────┼───────┼─────────┘
             │       └──────────► ステレオ音声
             ▼
   ┌───────────────────┐
   │ 320×120 framebuffer│
   └─────────┬─────────┘
             │
       ┌─────┴─────┐
       ▼           ▼
  LEDパネル1   LEDパネル2
    160×120      160×120
```

Pixel Twinsでは、ゲームロジック、描画、音声生成をプラットフォーム非依存の共通C++で実装します。
macOS版は完成したフレームバッファをSDL3で表示し、実機版は同じデータをLEDパネルへ転送します。
実機へ書き込む前にPC上でゲームを開発・デバッグでき、PC版だけ挙動が異なる二重実装を避けられる
ことが、この設計の中心です。

## macOSで試す

macOS版にはC++17、CMake、SDL3が必要です。

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel
ctest --test-dir build --output-on-failure
./build/examples/framebuffer/pixel_twins_framebuffer_example
```

SDL3はゲームエンジンの代替ではなく、実機と同じ共通フレームバッファをウィンドウへ表示するための
薄い接続層です。

## 実機を作る

実機はRP2350搭載ボードを中心に、160×120ピクセルのGS6263搭載LEDパネル2枚、
USBゲームコントローラー2台、音声出力回路で構成します。

![Pixel Twinsコントローラー基板](hardware/docs/pcb-front.png)

回路図、BOM、Gerberを[`hardware/`](hardware/README.md)で公開しています。

資料の構成、製造データの扱い、現在分かっている注意点は
[`hardware/README.md`](hardware/README.md)にまとめています。RP2350側の実装と信号割り当ては
[RP2350移植設計](docs/rp2350_port.md)を参照してください。

## プロジェクトの状態

現在の実装には、8ビットパレット式ダブルフレームバッファ、BG・スプライト・プリミティブ・
フォント描画、固定長スプライトアロケーター、SDL3入出力、RP2350のLEDパネル駆動、
2系統のUSBホスト、48kHzステレオ音声が含まれます。

APIとハードウェアは開発中であり、互換性を保たず変更する場合があります。
